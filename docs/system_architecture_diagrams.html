Section 1: Executive Topology

1. Executive Summary & System Topology

VRS COMPUTER is a high-performance, cyber-luxe hardware retail and custom PC workshop operating in Phnom Penh, Cambodia. The web platform delivers a client-side architecture with zero database latency, complete offline support, dynamic admin control, dual-currency processing (USD & KHR), and native integration with the National Bank of Cambodia’s Bakong KHQR payment infrastructure.

System Component Topology & Interaction Flow

Key Architecture Pillars

⚡ Zero-Latency Client Engine

Pure Vanilla JS & CSS architecture guarantees maximum render speed, zero npm runtime dependencies, and seamless compatibility across all iOS, Android, and Windows browsers.

🔄 Full-Duplex Storage Sync

The Admin Controller writes structured JSON directly to the browser storage layer. The storefront detects and hydrates custom products, exchange rates, and hotlines instantly.

🇰🇭 Cambodia-Native Commerce

Dynamic dual-currency calculations ($1 USD = 4,100៛) across all product cards, quotes, and carts. Official ABA KHQR modal renders exact account credentials with 1-click clipboard copy.

🛡️ Safe Fallback Mechanism

If local storage is cleared or uninitialized, the system gracefully falls back to default seed inventory (24 products, 30 builder parts, verified ABA credentials) without breaking.

2. Admin Controller Workflow & Data Pipeline

The Admin Controller (admin.html) is an executive dashboard allowing non-technical store managers to fully administer the customer storefront without writing code.

Admin Input to Frontend Render Pipeline

Detailed Admin Operations

Operation Admin Action Data Persistence Frontend Result
Add New Product Fill title, brand, category, price USD, upload photo or paste image URL. vrs_custom_products array unshifted with new product object. Appears instantly at the top of the Catalog grid with dual USD/KHR prices and add-to-cart buttons.
Update ABA QR Upload new ABA QR code image or update account name / USD / KHR numbers. Base64 data URL saved in vrs_store_settings.abaQrImage. The customer KHQR payment modal immediately renders the updated QR card and copy buttons.
Update Hotline & TG Change phone number or Telegram username in Settings. vrs_store_settings.hotline and vrs_store_settings.telegramHandle. Syncs across ticker, floating call buttons, header, showroom map, and digital invoices.
1-Click Backup Click "Download Store Backup (.json)". Blob download of entire store catalog, parts, settings, and orders. Allows restoring full inventory onto any new device or web browser in 1 second.

Section 4: PC Builder Studio Engine

4. Interactive PC Builder Studio & Compatibility Engine

The PC Builder Studio (js/builder.js and js/builder-data.js) is a custom configurator designed for enthusiasts and creators. It enforces hardware compatibility in real time.

PC Builder Real-Time Validation Pipeline

Builder Compatibility Rules

Check Type Source Slot Target Slot Validation Logic
CPU & Motherboard Socket CPU.socket Motherboard.socket Strict equality (e.g. LGA1700 === LGA1700 or AM5 === AM5). Warns if socket mismatch prevents mounting.
Power Headroom CPU.tdp + GPU.tdp + 100W PSU.wattage Ensures Power Supply unit wattage satisfies total thermal TDP + 150W safety overhead to prevent system shutdowns.
Cooling Capacity CPU.tdp Cooler.capacity Checks if 360mm / 240mm liquid AIO is recommended for processors exceeding 200W TDP (e.g. Core i9-14900KS).
